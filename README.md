# sextant-audio

Pre-generated TTS audio for [Sextant](https://pkocourek.com/sextant/) card stems.

This repo is a **publish artifact**: every file under `audio/` and the `manifest.json`
are generated by `tools/tts_gen.js` in `study-deck-private`. Do not hand-edit them —
regenerate instead. The generator is incremental: files are named by content hash
(`audio/<lang>/<cardId>-<hash8>.mp3`), so only changed stems are re-rendered.

    node tools/tts_gen.js --course ep1 --dry-run    # cost it out, writes nothing
    node tools/tts_gen.js --course ep1              # render the missing files

`hash8` is djb2 over `"<normVersion> <rawSpokenText>"`, where `rawSpokenText` is
exactly what the engine's `speakCard()` derives from `card.q`. Bumping
`normVersion` changes every file name and forces a full re-render.

Served via GitHub Pages at `https://pkocourek.com/sextant-audio/`.
The Sextant engine fetches `manifest.json`, plays the mp3 when a card has one,
and falls back to Web Speech otherwise.

Layout:

```
manifest.json
audio/<lang>/*.mp3     # lang ∈ en-US, es-ES, cs-CZ, ru-RU
```

```json
{
  "version": 1,
  "generatedAt": "<ISO8601>",
  "normVersion": 1,
  "voices": { "<lang>": "<provider>:<voiceId>" },
  "cards": { "<lang>/<cardId>": "audio/<lang>/<cardId>-<hash8>.mp3" }
}
```
