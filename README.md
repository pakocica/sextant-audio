# sextant-audio

Pre-generated TTS audio for [Sextant](https://pkocourek.com/sextant/) card stems.

This repo is a **publish artifact**: every file under `audio/` and the `manifest.json`
are generated by `tools/tts_gen.mjs` in `study-deck-private`. Do not hand-edit them —
regenerate instead. The generator is incremental: files are named by content hash
(`audio/<lang>/<cardId>-<hash8>.mp3`), so only changed stems are re-rendered.

Served via GitHub Pages at `https://pkocourek.com/sextant-audio/`.
The Sextant engine fetches `manifest.json`, plays the mp3 when a card has one,
and falls back to Web Speech otherwise.

Layout:

```
manifest.json          # { version, generatedAt, voices: {lang: voice}, cards: { "<lang>/<cardId>": "audio/<lang>/<cardId>-<hash8>.mp3" } }
audio/<lang>/*.mp3     # lang ∈ en-US, es-ES, cs-CZ, ru-RU
```
